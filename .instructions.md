# 3D Kenji Project Instructions

## Project Overview
3D Kenji is a Python-based backend project using FastAPI for a 3D object management system with plugin architecture support.

## Project Structure
- **src/backend/**: FastAPI application, main.py is the entry point
- **src/backend/api/**: API route definitions
- **src/backend/core/**: Core business logic
- **src/backend/db/**: Database models and migrations
- **src/backend/models/**: Data models
- **src/backend/plugins/**: Plugin system
- **tests/**: Test suite with pytest
- **migrations/**: Alembic database migrations
- **docs/**: Documentation and guides

## Technology Stack
- **Language**: Python 3.11
- **Framework**: FastAPI
- **Database**: PostgreSQL
- **Package Manager**: uv
- **Testing**: pytest
- **Database Migrations**: Alembic

## Development Environment
- **Dev Container**: Running with Docker Compose
- **Virtual Environment**: `.venv/` (Python 3.11)
- **Server**: Runs on `localhost:8000` in dev container

## Common Commands
- `pytest`: Run tests
- `uvicorn src.backend.main:app --reload`: Run dev server
- `alembic upgrade head`: Apply database migrations
- `alembic revision --autogenerate -m "description"`: Create migration

## Code Style & Practices
- Follow PEP 8
- Use pytest for testing
- Document API endpoints with docstrings
- Use type hints throughout

## When Providing Assistance
- Focus on FastAPI patterns and best practices
- Consider the plugin architecture when suggesting changes
- Reference existing test patterns for new tests
- Check migrations before suggesting database schema changes
